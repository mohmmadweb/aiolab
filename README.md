# آیولب (Aiolab) — پلتفرم کاریابی تخصصی آزمایشگاه 🧪

پروتوتایپ (Prototype) وب‌سایت کاریابی تخصصی پرسنل آزمایشگاه‌های تشخیص طبی و پژوهشی.

**دامنه:** [aiolab.ir](https://aiolab.ir)

## درباره این نسخه

این یک **پروتوتایپ کاملاً استاتیک** است (HTML/CSS/JS خالص، بدون بک‌اند):

- تمام داده‌ها (آگهی‌ها، آزمایشگاه‌ها، دوره‌ها و...) نمونه و در `assets/js/data.js` هستند.
- ورود و ثبت‌نام **دمو** است و با `localStorage` شبیه‌سازی می‌شود — با هر ایمیل/رمزی می‌توان وارد شد.
- هدف: نمایش کامل UX/UI نسخه‌های ۱ و ۲ نقشه راه محصول.

## صفحات

| صفحه | فایل |
|---|---|
| صفحه اصلی | `index.html` |
| فرصت‌های شغلی + فیلتر تخصصی | `jobs.html` |
| جزئیات آگهی + تطبیق هوشمند (دمو) | `job.html` |
| آزمایشگاه‌های عضو | `labs.html` / `lab.html` |
| مجله آیولب | `magazine.html` |
| آموزش و آزمون مهارت | `courses.html` |
| جامعه آزمایشگاهی (شبکه اجتماعی) | `community.html` |
| ورود / ثبت‌نام (دمو) | `login.html` / `register.html` |
| داشبورد کارجو (رزومه‌ساز، درخواست‌ها، مسیر ارتقاء) | `dashboard.html` |
| پنل کارفرما (ثبت آگهی، متقاضیان، بانک رزومه، تعرفه‌ها) | `employer.html` |

## اجرای محلی

کافی است `index.html` را در مرورگر باز کنید، یا:

```bash
npx serve .
```
