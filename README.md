# آیولب (Aiolab) — پلتفرم کاریابی تخصصی آزمایشگاه 🧪

پروتوتایپ (Prototype) وب‌سایت کاریابی تخصصی پرسنل آزمایشگاه‌های تشخیص طبی و پژوهشی.

**دامنه:** [aiolab.ir](https://aiolab.ir)

## درباره این نسخه

این یک **پروتوتایپ کاملاً استاتیک** است (HTML/CSS/JS خالص، بدون بک‌اند):

- تمام داده‌ها (آگهی‌ها، مراکز، آزمون‌ها، سؤالات MBTI و...) نمونه و در `assets/js/` هستند.
- ورود و ثبت‌نام **دمو** است و با `localStorage` شبیه‌سازی می‌شود.
- گواهی‌های آزمون، هشدارهای شغلی، نتیجه MBTI و خودارزیابی نیز در `localStorage` نگه‌داری می‌شوند.

## نقشه — انتخاب سرویس‌دهنده

موتور نقشه **Leaflet** است و کاشی‌ها قابل تعویض‌اند:

| گزینه | کلید لازم؟ | وضعیت |
|---|---|---|
| **OpenStreetMap** (پیش‌فرض) | ❌ ندارد | فعال و بدون هزینه |
| **نشان (Neshan)** | ✅ کلید رایگان وب | آماده؛ فقط کلید لازم دارد |
| **بلد (Balad)** | — | فقط `iframe embed` دارد و برای پین‌گذاری چندگانه مناسب نیست |

برای سوییچ به نشان، کلید رایگان را از [developer.neshan.org](https://developer.neshan.org) بگیرید و در `assets/js/map.js` قرار دهید:

```js
const AIO_MAP_CONFIG = {
  provider: "neshan",
  neshanKey: "کلید-وب-شما",
  ...
};
```

## چندزبانه

کلیدهای ترجمه در `assets/js/i18n.js` هستند و در HTML با `data-i18n="nav.jobs"` استفاده می‌شوند.
افزودن زبان جدید = افزودن یک شیء به `AIO_LANGS` و یک بلوک به `DICT`. جهت صفحه (`rtl`/`ltr`) خودکار تنظیم می‌شود.

## اجرای محلی

کافی است `index.html` را در مرورگر باز کنید، یا:

```bash
npx serve .
```
