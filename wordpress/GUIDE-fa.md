# راهنمای مدیریت آیولب از پیشخوان

ورود: `https://aiolab.ir/wp-admin` — همه‌چیز سایت از همین‌جا ویرایش می‌شود؛ هیچ متنی در کد نیست.

## کجا چه چیزی را ویرایش کنم؟

| می‌خواهم… | مسیر در پیشخوان |
|---|---|
| لوگو، متن فوتر، کپی‌رایت، نوار «خانواده آیو» | **تنظیمات آیولب ← برند و فوتر** |
| ایمیل پشتیبانی، تلفن، نشانی، شبکه‌های اجتماعی | **تنظیمات آیولب ← اطلاعات تماس** (در فوتر و صفحه تماس نمایش داده می‌شود) |
| کد اینماد و ساماندهی، لینک اپلیکیشن | **تنظیمات آیولب ← نمادها و اپلیکیشن** |
| منوی بالای سایت و ستون‌های فوتر | **نمایش ← فهرست‌ها** (زیرعنوان = «توضیحات»، آیکن = کلاس CSS مثل `icon-pin`) |
| متن هر صفحه (خانه، درباره ما، تعرفه‌ها، …) | **برگه‌ها ← ویرایش برگه** (هر بخش یک بلوک HTML است؛ عناصر دارای `id` را حذف نکنید) |
| آگهی‌های شغلی | **آگهی‌های شغلی** (تأیید آگهی کارفرما = انتشار آن) |
| مراکز و آزمایشگاه‌ها (لوگو، نقشه، حقوق، امتیاز پایه) | **مراکز و آزمایشگاه‌ها** |
| درخواست‌های همکاری و وضعیتشان | **آگهی‌های شغلی ← درخواست‌های همکاری** |
| دوره‌ها، سرفصل، متن و ویدئوی درس‌ها، سؤالات آزمون درس | **دوره‌های آکادمی** (کادر «سرفصل و محتوای درس‌ها») |
| مسیرهای یادگیری، مدرسان، ارائه‌دهندگان | زیرمنوهای **دوره‌های آکادمی** |
| آزمون‌های مهارت و سؤالاتشان، گواهی‌های صادرشده | **آزمون‌های مهارت** |
| خدمات، قیمت‌ها، اشتراک‌ها، و «آنچه پس از پرداخت فعال می‌شود» | **خدمات و تعرفه‌ها** |
| سفارش‌ها و تأیید پرداخت دستی | **خدمات و تعرفه‌ها ← سفارش‌ها** (وضعیت را «پرداخت‌شده» کنید تا خدمت خودکار فعال شود) |
| سؤالات پرتکرار | **سؤالات پرتکرار** |
| مقاله‌های مجله | **نوشته‌ها** (کادر «نمایش در مجله آیولب» برای آیکن و رنگ کارت) |
| پست‌های جامعه | **جامعه آزمایشگاهی** |
| نظرات مراکز و دوره‌ها | **دیدگاه‌ها** (تأیید/رد) |
| پیام‌های فرم تماس، درخواست‌های تبلیغات و مشاوره | **پیام‌های تماس** |
| گزینه‌های فرم‌ها و فیلترها (نوع همکاری، مزایا، بازه حقوق، …) | **تنظیمات آیولب ← فهرست‌های پایه** |
| بخش‌های آزمایشگاهی، دسته‌های دوره، گروه‌های خدمات | زیرمنوی «بخش‌ها/دسته‌ها» زیر هر نوع محتوا |
| سؤالات MBTI و خودارزیابی | **تنظیمات آیولب ← MBTI و خودارزیابی** |
| قوانین (آگهی پولی، بانک رزومه پولی، انتشار بدون بازبینی) | **تنظیمات آیولب ← قوانین کسب‌وکار** |
| درگاه پرداخت | **تنظیمات آیولب ← پرداخت** |

ویجت «آیولب — کارهای در انتظار» در صفحه‌ی اول پیشخوان، آگهی/مرکز/دوره/آزمون در انتظار تأیید، نظرات، سفارش‌ها و پیام‌های جدید را نشان می‌دهد.

## داده‌های نمونه
همه‌ی محتوای نمونه در فهرست‌ها برچسب «نمونه» دارد و مثل بقیه قابل ویرایش است. برای حذف یکجا: **تنظیمات آیولب ← ابزارها ← حذف همه‌ی داده‌های نمونه** (به زباله‌دان می‌رود).

## راه‌اندازی رسمی
1. **تنظیمات آیولب ← حالت به‌زودی**: تیک را بردارید و ذخیره کنید (سایت برای همه و موتورهای جستجو باز می‌شود).
2. تا آن زمان، لینک پیش‌نمایش همان صفحه را برای همکاران بفرستید.

## وصل کردن درگاه پرداخت
**تنظیمات آیولب ← پرداخت**: «درگاه زرین‌پال» یا «درگاه زیبال» را انتخاب کنید، مرچنت را وارد و تیک «حالت آزمایشی» را بردارید. تا آن زمان روش «دستی» فعال است: سفارش ثبت می‌شود و شما پس از دریافت وجه، وضعیت سفارش را «پرداخت‌شده» می‌کنید.
